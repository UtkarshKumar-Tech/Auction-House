# Auction House

A console-based Auction House Management System developed in C++ using basic data structures.

## Project Objective

The project simulates an Auction House with different divisions and services.

The system will gradually include:

- User Management
- Upperworld Auctions
- Regular and VIP Membership
- Bidding System
- Underworld Information Services
- Commission Requests
- Admin / Owner Management
- Transaction Records
- Reports

## Current Progress

### Level 1 - User Management

Implemented:

- User Registration
- Unique User ID generation
- Duplicate email checking
- User Login
- User Profile
- Logout
- User Linked List
- Dynamic memory allocation

## Data Structure Used

### Linked List

A singly linked list is used to store registered users dynamically.

Example:

User 1 -> User 2 -> User 3 -> NULL

Each user is stored inside a node.
